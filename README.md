# 全家備課與學習小幫手

> **第一次用 AI、完全不知道這是什麼？** 👉 [**點我看 30 秒白話入門指南**](./00_新手從零開始指南.md)
> 不管你是完全沒用過 AI 的新手，還是使用**學校／公司不能裝軟體的電腦**，只要會打字選「1、2、3」就能輕鬆上手！

---

## 這個小幫手能幫你做什麼？

- **老師出考卷神器**：把舊考卷丟給它就能學會你的排版風格，自動對齊台灣課本版本並先幫你驗算，一次做好 **Word 題目卷＋答案解析卷**。
- **學生複習變好玩**：把課本重點變成點開就能玩的**互動闖關小遊戲**、左觀念右練習的複習網頁。
- **簡報、海報與 1 分鐘動畫**：輕鬆產出 PowerPoint 簡報、一張看懂重點的彩色考前海報，以及 60 秒中文解說短片。
- **完全不用背指令**：平常就像跟朋友傳 LINE 一樣打字，而且小幫手每次都會給你 **1、2、3 數字選單**，打個數字就能搞定！

---

## 第一步：打開 Gemini，貼上這段話就開始（所有人統一入口）

不用先下載任何軟體！只要打開 [Gemini 網頁版](https://gemini.google.com/)（或手機 Gemini App），把下面這段話**整段複製貼上、按送出**：

```text
哈囉！我是第一次用 AI 的新手，家人推薦我用這套學習與備課小幫手，請幫我讀這個公開網頁裡的 AGENTS.md 和 00_新手從零開始指南.md：
https://github.com/arnohsu-0930/family-learning-assistant

請先用 30 秒最簡單的白話（完全不要用電腦專有名詞，也不要說什麼 Skill 或 Agent），告訴我你準備好之後能幫我做什麼、平常要怎麼跟你互動，再問我現在用的是私人電腦還是學校／公司電腦、能不能自行安裝軟體，用數字選單一步步帶我開始！
```

*(貼上後，Gemini 會先用超白話的方式跟你自我介紹，再問你的電腦能不能裝軟體，一步步帶你往下走！)*

---

## 第二步（進階完整版）：裝好桌面程式 AGY 後貼這一句

如果剛剛 Gemini 確認你的電腦可以安裝免費的 **Google Antigravity（AGY）**，等你裝好並打開桌面新建的資料夾後，把下面這一句貼進 AGY 送出，它就會自動幫你建好 4 個資料夾並把所有出考卷與小遊戲工具一次準備好：

```text
請幫我讀取 https://github.com/arnohsu-0930/family-learning-assistant 裡的 INSTALL_FOR_AGENTS.md 與 AGENTS.md，照裡面的步驟在背景自動幫我把 4 個資料夾和全部教學工具準備好，完成後用最簡單的白話告訴我可以用來做什麼，並給我數字選單馬上試試看！
```

*(如果是在學校／公司不能裝軟體的電腦，完全不需要做第二步，直接在 Gemini 裡照 [《00_新手從零開始指南》情境 B](./00_新手從零開始指南.md#情境-b學校公司電腦權限被鎖不能裝軟體只能開瀏覽器免安裝-3-招) 就能用囉！)*

## 自動幫你整理好的 4 個資料夾

| 資料夾名稱 | 用途說明 |
| :--- | :--- |
| `01_過去考卷範本` | 老師可以把過去 2～3 份 Word／PDF 舊考卷放進來，讓小幫手學你的風格 |
| `02_互動複習小遊戲` | 內建 5 款現成互動複習小遊戲，點兩下就能直接玩 |
| `03_做好的成品放這裡` | 之後做出來的 Word 考卷、簡報、海報、動畫與小遊戲都會整齊放這裡 |
| `04_課本與講義放這裡` | 想用自己的課本照片或 PDF 講義出題、做重點整理，直接丟進來就好 |
