# 全家備課與學習小幫手

> **第一次使用請先看這裡**：👉 [**點我閱讀《00_新手從零開始指南》**](./00_新手從零開始指南.md)
> 不管你是用**家裡筆電**，還是**學校／公司權限被鎖、不能裝軟體的電腦**，裡面都有零基礎、完全白話的一步步教學！

這是一套為全家人（老師、學生、自學者）設計的零門檻 AI 備課與學習工具。不會寫程式也沒關係，全程只要「**打數字選 1、2、3**」就能出 Word 考卷、做互動複習小遊戲、60 秒解說動畫、教學簡報與重點海報。

---

## 開始前先確認你的電腦

- **家裡筆電**，或**可以自行安裝軟體的公司／學校電腦** → 下載安裝 Google Antigravity（AGY），登入自己的 Google 帳號，在桌面建一個資料夾，貼上底下的「唯一一句啟動口令」就搞定（免申請 GitHub 帳號）。
- **學校／公司電腦不能裝軟體** → 直接看 [《00_新手從零開始指南》情境 B](./00_新手從零開始指南.md#情境-b學校公司電腦權限被鎖不能裝-agy只能開瀏覽器免安裝-3-招)，只要打開瀏覽器用 Gemini 網頁版就能直接上工！

---

## 給家人的「唯一一句啟動口令」

在 Google Antigravity（AGY）打開你桌面新建的資料夾後，把下面這句話**整句複製貼上、按送出**即可：

```text
請幫我讀取 https://github.com/arnohsu-0930/family-learning-assistant 裡的 INSTALL_FOR_AGENTS.md 與 AGENTS.md，先問我這台電腦是私人還是公司／學校電腦、能不能自行安裝軟體，再照裡面的步驟自動幫我把資料夾和全部教學技能裝好，最後用親切的白話數字選單帶我開始！
```

## 裝好後可以幫你做什麼？

- **自動記住每位家庭成員**：不寫死年級或科目，換人用、升年級或換新學期都會自動更新。
- **主動查好教育部核准教材**：國中小（康軒／南一／翰林）與五專／高中職／大專專業用書直接列選項給你挑，還能加選因材網、均一、歷屆考古題與生活素養題。
- **老師出考卷神器**：把舊考卷拉進資料夾就能學會你的排版風格，自動驗算後一次產出 Word 題目卷＋答案卷。
- **5 種好玩複習教材**：互動小遊戲網頁、左觀念右互動複習網頁、60 秒中文解說動畫、PowerPoint 簡報、一張看懂重點的彩色海報。

## 自動建立的 4 個資料夾用途

| 資料夾名稱 | 用途說明 |
| :--- | :--- |
| `01_過去考卷範本` | 老師可以把過去 2～3 份 Word／PDF 舊考卷放進來，讓小幫手學你的風格 |
| `02_互動複習小遊戲` | 內建 5 款現成互動複習小遊戲，點開就能直接玩 |
| `03_做好的成品放這裡` | 之後做出來的 Word 考卷、簡報、海報、動畫與小遊戲都會整齊放這裡 |
| `04_課本與講義放這裡` | 想用自己的課本照片或 PDF 講義出題、做重點整理，直接丟進來就好 |
